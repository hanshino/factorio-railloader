# Bulk Rail Loader (Continued)

**Bulk Rail Loader (Continued)** is a faithful Factorio 2.0 continuation of the original
Bulk Rail Loaders mod. It provides fast bulk loading and unloading for cargo
wagons, with a focus on keeping large rail stations compact and practical.

## Features

- Bulk cargo wagon loading and unloading in approximately five seconds.
- Circuit-network control for station automation.
- Compatibility with Logistic Train Network (LTN) setups.
- Interface chests for convenient item transfer and buffering.
- Original-style rail loader and unloader entities, recipes, and research.

This port preserves the original mod's intended behavior where possible. The
features above are documented by the mod and its source; compatibility with
every possible mod combination has not been independently tested.

## Compatibility and scope

This release targets newly created Factorio 2.0 maps. Conversion of existing
Factorio 1.1 saves has not been verified, so make a backup before attempting
one. Multiplayer users must use the same mod version and settings.
